# 북빌리지 스쿨 (BookVillage School)

고전·인문학 독서 활동을 게이미피케이션과 3D 메타버스 학교에 결합한 웹게임 프로토타입.
Three.js(CDN) 단일 파일(`index.html`) 구조 — 빌드 과정 없음.

## 실행
```bash
node serve.js   # http://localhost:8765
```
(ES module 사용으로 `file://` 직접 열기는 불가, 정적 서버 필요. 인터넷 필요: Three.js·폰트 CDN)

## 구조 (index.html 내부)
- 데이터: `BOOKS`(책·스토리 장면), `SHOP`, `TIERS`, `HASHTAGS`
- 3D 아바타: `buildAvatar` (six-sense `avatar.ts` 옵션 재사용)
- 씬: `SCENES.campus / library / classroom / art / music / creator`
- 활동: `coopGame`(15소년 표류기 협동), `playStory`, `writeReview`
- AI 표지: `drawCover` — 현재는 키워드 기반 캔버스 생성(대역). 실제 AI API로 교체 예정
- 저장: localStorage (`bookvillage-save-v1`)

## 이번에 추가된 기능
- **원형 캠퍼스:** 분수 광장을 중심으로 도서관·교실·미술실·음악실이 빙 둘러서 있고, 둥근 산책길로 이어져요. (`STATIONS`에서 각도만 바꾸면 위치 변경)
- **☕ 구름 상점 트럭:** 상점이 교실 밖으로 나와 캠퍼스 왼쪽에 커피트럭처럼 서 있어요. (`shopTruck`)
- **캐릭터 꾸미기 상품:** 포인트로 머리(꽃 화관·토끼 귀·마법사 모자·왕관), 등(책가방·망토·날개), 손(마법책·풍선) 아이템을 사서 3D 캐릭터에 입혀요. 👕 꾸미기 화면에서 바꿔 입기 가능.
- **🎼 책 음악 만들기 (음악실):** 크롬 뮤직랩처럼 칸을 눌러 작곡해요. 피아노 8음 + 드럼 2종, 1마디 4칸, 최대 8마디. "건반으로 녹음"을 켜면 건반 친 음이 차례로 기록돼요. 저장하면 그 책의 디지털 북·학급 문집에 ▶ 듣기와 함께 실려요. (+15P)
- **💬 이모지 말풍선:** 서평을 쓸 때 책을 이모지 3개로 표현하면 내 캐릭터 머리 위에 말풍선으로 떠요. 친구들(NPC)도 가끔 자기 책 말풍선을 띄워요. 💬 버튼으로 책 바꾸기·끄기.
